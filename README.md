# AI × HUMAN INTERFACE ATLAS 300

Three.jsを除く300のツールを、AI適性・人間適性・トークン増幅・修正容易性・信頼性の5軸で探索する、自己完結型のインタラクティブ図鑑です。

## 主な機能

- 同点セルを残りの評価軸で細分化する連続分布散布図
- 5軸の非支配候補（Pareto候補）表示
- 軸・円サイズ・密度表示の切り替え
- 目的別適性ミキサーと重み付き推薦
- 30領域ヒートマップ
- 発見レンズ
- 最大5件のツール構成ビルダー
- 比較、検索、絞り込み、保存、共有URL、JSON/CSV出力

一般公開用の静的サイトです。機密情報・APIキー・認証情報は含みません。
